# sufyansuleman.github.io

Source of my personal academic website: **https://sufyansuleman.github.io/**

The site presents my research tools (R packages, a reference pipeline and an interactive
browser), courses, publications, projects and CV in one place, so that people can find,
use and build on the work, and get in touch.

Built with Astro and Tailwind, deployed to GitHub Pages by the workflow in `.github/workflows/`.
Publications are pulled from ORCID on every deploy. Notes on editing and adding content are in
[docs/MAINTAINING.md](docs/MAINTAINING.md).
