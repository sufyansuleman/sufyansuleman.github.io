## About this course

Getting Started with R is a self-paced introduction to R and RStudio for people with no prior programming experience. It is designed for learners moving from spreadsheet-based tools such as Excel or STATA and takes roughly 6-9 hours to complete.

## Learning objectives

- Install R and RStudio and navigate the RStudio IDE
- Manage packages and understand basic R syntax
- Work with variables, vectors and core operations
- Use R Markdown for reproducible documentation
- Understand data structures: vectors, data frames, lists
- Import, visualise and troubleshoot real data

## Who it is for

Beginners with no programming background who have a computer with a stable internet connection and basic computer literacy.

## Curriculum

- **Module 1, Getting Started**
  - R and RStudio installation and basic syntax
- **Module 2, Working with Data**
  - Data structures and package management
- **Module 3, Data in Action**
  - Real-world data import, exploration and visualisation

3 modules, 9 sessions in total.

## Format & materials

Each session follows the same structure: an overview, explanatory content with code examples, "try it yourself" prompts, numbered exercises with reveal-able solutions, and self-check questions. Learners type code themselves rather than copying. A glossary and troubleshooting guide are included.
